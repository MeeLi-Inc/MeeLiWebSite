## Privacy Policy Updates

Use the following details to resolve the open Privacy Policy placeholders:

### Data Storage & Security

MeeLi stores and processes data using secure infrastructure in the United States. User data is hosted on Amazon Web Services (AWS) in the United States, including the `us-east-1` region in Northern Virginia, with primary application data stored on MongoDB Atlas. Both providers meet industry standards for security and reliability.

AWS supports cloud hosting, file storage through Amazon S3, email delivery through Amazon SES, account authentication through Amazon Cognito, background processing, and content delivery infrastructure. MongoDB Atlas stores primary application data, including accounts, posts, and Journey content.

### How to Request Deletion

Users can delete their account at any time from within the app:

`Profile -> Settings -> Delete Account`

If a user needs help with the process or wants to submit a written deletion request, they can contact MeeLi at `support@meeli.social`.

### Third-Party Services

MeeLi currently relies on a small, vetted set of infrastructure and platform providers:

- Amazon Web Services (AWS): cloud hosting, file storage, email delivery, account authentication, background processing, and content delivery infrastructure.
- MongoDB Atlas: primary application database for accounts, posts, and Journey content.
- Apple App Store and Google Play Store: app distribution. Their own policies govern installation, device-level permissions, and platform-level data.

MeeLi does not currently use third-party advertising networks, behavioral analytics tools, or marketing tracking SDKs.
